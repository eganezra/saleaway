### Logger

The architecture requires a "structured JSON logger in `packages/core`" giving "one log shape everywhere" (NFR11), and the coding standards forbid direct `console.log` and forbid `packages/core` from calling the clock. The architecture does not define the logger's API or fields, so use this minimal design, which follows both rules. [Source: architecture/tech-stack.md#technology-stack-table (Logging row); architecture/coding-standards.md#critical-fullstack-rules]

```typescript
// packages/core/src/logger.ts (shape, not final code)
export type LogLevel = 'debug' | 'info' | 'warn' | 'error';

export interface LoggerOptions {
  now: () => Date;                 // supplied by the caller, core never reads the clock
  write: (line: string) => void;   // supplied by the caller, core never touches console
}

export interface Logger {
  debug(message: string, fields?: Record<string, unknown>): void;
  info(message: string, fields?: Record<string, unknown>): void;
  warn(message: string, fields?: Record<string, unknown>): void;
  error(message: string, fields?: Record<string, unknown>): void;
}

export function createLogger(options: LoggerOptions): Logger;
```

Each call writes **one line of JSON**: `{ "level": "...", "message": "...", "time": "<UTC ISO 8601>", ...fields }`. `apps/web/src/lib/log.ts` is the only place that supplies `now: () => new Date()` and `write: (line) => console.log(line)`. Cloudflare's Workers Logs reads JSON log lines, which is why one JSON line per call is used. Add `Error` serialisation (message and name) so that `logger.error('x', { err })` does not log `{}`.
